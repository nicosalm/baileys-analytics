# Supabase auth email templates

Generated by `node api/scripts/render-auth-emails.mts` from the shared layout in `api/src/services/email-layout.ts`. Do not edit the html by hand; change the script or the layout and regenerate.

Paste each file into Supabase: Authentication > Email Templates, and set the subject.

| Dashboard template   | File                    | Subject                                      |
| -------------------- | ----------------------- | -------------------------------------------- |
| Confirm signup       | `confirm-signup.html`   | Confirm your email for Baileys Analytics     |
| Reset Password       | `reset-password.html`   | Reset your Baileys Analytics password        |
| Change Email Address | `change-email.html`     | Confirm your new email for Baileys Analytics |
| Magic Link           | `magic-link.html`       | Your Baileys Analytics sign-in link          |
| Invite user          | `invite-user.html`      | You're invited to Baileys Analytics          |
| Reauthentication     | `reauthentication.html` | Your Baileys Analytics confirmation code     |
